## Brand & Style

This design system expresses a disciplined, institutional AI intelligence. It marries the structured rigor of enterprise infrastructure with the refined, cinematic craft of modern engineering tools. The identity projects authority, engineering excellence, and deliberate velocity.

### Design Movement
Modern Enterprise Hybrid: A calibrated balance of pure utilitarian function, tactile micro-elevations, and atmospheric depth. The interface utilizes a 60/40 visual weight hierarchy—dominant crisp off-white canvas surfaces structured alongside deep, technical midnight panels for complex data states, telemetry, and terminal output. 

### Core Attributes
- **Architectural & Systematic:** Every module adheres strictly to an absolute spatial geometry. Layouts feel constructed rather than merely assembled.
- **Electric Precision:** Functional high-energy accents guide operator attention without generating visual noise.
- **Calibrated Contrast:** Deep midnight zones establish focus, while neutral slate surfaces ensure sustained readability during high-density workflows.

## Colors

The palette is engineered for high-density legibility and selective optical pull. High-saturation accents are strictly functional, reserved for actionable triggers, primary pathways, and system state transitions.

### Color Tokens & Roles

- **Primary (`#2563EB` - Electric Blue):** Core action driver. Used for primary interactive triggers, active navigation markers, selection rings, and high-priority workflow confirmations.
- **Secondary (`#06B6D4` - Cyan Precision):** Computational and analytical indicators. Applied to automated workflows, real-time sync indicators, live telemetry graphs, and secondary data filters.
- **Tertiary (`#8B5CF6` - Synthesized Violet):** Generative AI and mutation states. Reserved strictly for generative transformations, prompt models, synthetic outputs, and elevated badges.
- **Neutral Dark (`#0B1220` to `#111827` - Midnight Navy):** The structural counterweight. Defines technical command views, terminal windows, code inspectors, and elevated dark mode contextual sheets.
- **Neutral Surface (`#F8FAFC` to `#FFFFFF` - Warm Canvas):** Primary workspace backdrops, high-density table panels, form structures, and documentation hubs.
- **Subtle Stroke (`#E2E8F0` / dark: `rgba(255, 255, 255, 0.08)`):** Micro-hairlines providing separation without optical mass.

### Contrast Discipline
Interactive text elements must meet a minimum contrast ratio of 4.5:1 against their immediate backdrops. Accents like `#06B6D4` must not be used for small running text on light surfaces; they are strictly restricted to graphical iconography, badges, or contained within dark surfaces.

## Typography

Typography relies on a systematic deployment of `Inter` across all structural levels, utilizing its native OpenType features (`cv02`, `cv03`, `cv04`, `cv11` for technical legibility and precise tabular figures).

### Typographic Rules
- **Display & Headlines:** Tightly tracked negative letter spacing (`-0.02em` to `-0.03em`) creates a solid editorial header presence reminiscent of contemporary developer tools.
- **Body & Data:** Neutral tracking at standard sizes preserves effortless scanning in dense data tables and long-form AI conversational logs.
- **Labels & Micro-data:** Micro labels (`label-sm`) require uppercase rendering, `600` weight, and wide letter spacing (`0.04em`) to maintain sharp legibility when paired with telemetry readouts and system indicators.

## Layout & Spacing

The structural layout uses an architectural 12-column grid anchored by an 8pt spatial baseline. Component intervals strictly consume multiples of 4px and 8px to maintain vertical rhythm.

### Grid & Breakpoints
- **Desktop (1280px+):** 12-column fluid grid, max-width container 1440px. 24px (`1.5rem`) gutters, 48px (`3rem`) lateral margins.
- **Tablet (768px – 1279px):** 8-column grid. 24px (`1.5rem`) gutters, 32px (`2rem`) lateral margins.
- **Mobile (0px – 767px):** 4-column grid. 16px (`1rem`) gutters, 16px (`1rem`) canvas margins. Side-by-side analytical widgets stack into a unified column sequence.

### Layout Philosophy
Generous white space defines structural boundary sections (`space-2xl` to `space-3xl`), while dense workspaces—such as node graphs, model parameters, and table rows—tighten into compact spatial units (`space-xs` through `space-md`). This contrast prevents enterprise sprawl and prevents dashboard clutter.

## Elevation & Depth

Visual hierarchy combines low-contrast architectural borders with multi-layered, diffused ambient shadows and subtle glassmorphic surfaces.

### Tiers of Elevation

1. **Flat / Base Layer (`Level 0`):** Canvas color `#F8FAFC`. Zero elevation. Demarcated solely through 1px border lines in `#E2E8F0` or `#CBD5E1`.
2. **Interactive Cards & Panels (`Level 1`):** Pure `#FFFFFF` background with a hairline border (`#E2E8F0`) and an ambient shadow: `0 1px 3px 0 rgba(11, 18, 32, 0.04), 0 1px 2px -1px rgba(11, 18, 32, 0.02)`.
3. **Floating Overlays & Popovers (`Level 2`):** Dropdowns, context menus, and toolbars. Surface uses frosted white (`rgba(255, 255, 255, 0.85)` with `12px` backdrop blur) or deep midnight (`rgba(11, 18, 32, 0.90)` with `16px` backdrop blur). Shadow: `0 10px 15px -3px rgba(11, 18, 32, 0.08), 0 4px 6px -4px rgba(11, 18, 32, 0.03)`.
4. **Modals & Command Palettes (`Level 3`):** High focal depth. Surrounded by an ultra-thin highlight ring (`rgba(255, 255, 255, 0.15)` on dark, `rgba(11, 18, 32, 0.08)` on light) and cast by a wide atmospheric shadow: `0 25px 50px -12px rgba(11, 18, 32, 0.25)`.

## Shapes

The design system employs **Level 2 (Rounded)** curvature. This provides a balance between the mechanical precision of code-first tools and human-centered design.

### Geometry Hierarchy
- **Base Geometry (`rounded-md` / 8px):** Standard controls including text inputs, dropdown triggers, buttons, and secondary badges.
- **Container Geometry (`rounded-lg` / 16px):** Content modules, data visualization containers, slide-out inspector panels, and modal dialogs.
- **Surface Nesting Rule:** When elements are nested within containers, the internal border radius must equal the outer radius minus the intervening padding (`R_inner = R_outer - Padding`). A 16px container with 8px internal padding must host 8px children to avoid optical corner clashes.
- **Pill Exceptions:** Filter status pills, active processing indicators, and user avatars selectively employ full circular bounds (`rounded-full`).

## Components

### Buttons
- **Primary:** Solid `#2563EB` fill, white typography (`Inter 500`), subtle top inner highlight (`inset 0 1px 0 rgba(255, 255, 255, 0.2)`), 8px border radius, 36px total height. Hover: `#1D4ED8`. Active: scale `0.98`.
- **Secondary:** Surface `#FFFFFF`, hairline border `#E2E8F0`, typography `#0B1220`. Hover: `#F8FAFC` background with `#CBD5E1` border.
- **Dark Variant (Terminal / Midnight):** Background `rgba(255, 255, 255, 0.08)`, border `rgba(255, 255, 255, 0.12)`, typography `#FFFFFF`. Hover: `rgba(255, 255, 255, 0.14)`.

### Inputs & Fields
- **Default State:** Height 40px, background `#FFFFFF`, border 1px solid `#CBD5E1`, typography `#0B1220`, placeholder `#94A3B8`.
- **Focused State:** Border color `#2563EB`, paired with a 3px soft outer ring in `rgba(37, 99, 235, 0.15)`. No abrupt transitions; ease-out 150ms.
- **Inline Command / Prompt Input:** Single-line or auto-expanding multi-line with integrated trailing keyboard command tokens (`⌘K`) rendered in muted slate with a subtle border.

### Cards & Panels
- Constructed with `#FFFFFF` surfaces, 1px `#E2E8F0` border, 16px border radius, and internal padding of 24px (`space-lg`).
- When functioning as an active computation or node container, headers feature an integrated toolbar border-bottom (`#F1F5F9`) separating configuration from data outputs.

### Chips & Badges
- **Status Indicators:** Micro-padding (2px top/bottom, 8px left/right), 11px uppercase typography (`label-sm`).
- **Telemetry Chips:** Cyan background tint (`rgba(6, 182, 212, 0.1)`), cyan text (`#0891B2` on light, `#06B6D4` on dark), paired with a 6px static or pulsing operational dot.
- **AI / Generative Badges:** Restrained violet background tint (`rgba(139, 92, 246, 0.1)`), violet text (`#7C3AED` on light, `#A78BFA` on dark).

### Selection Controls (Checkboxes & Radios)
- 16px square (checkbox) or circle (radio), 1px solid `#CBD5E1`, background `#FFFFFF`.
- Checked: `#2563EB` background with clean white check or dot icon. Focus ring applies consistent `rgba(37, 99, 235, 0.2)` spread.

### Command Palette & Terminal Blocks
- **Floating Command Palette:** Centered, 640px wide, backdrop `#0B1220` with 95% opacity and 20px blur. 1px hairline border in `rgba(255, 255, 255, 0.1)`. Search input separated by a continuous line from dynamic result rows.
- **Code & Output Blocks:** Deep navy `#0B1220` background, high-contrast monospace code syntax, subtle copy action in the top-right corner that illuminates on hover.
